Every stable event ID was joined back to the corresponding
`sessions.db:session_events` row, including session, turn, call, and event
kind. Source-log/result SHA-256 values were recomputed before staging.
Replay completeness is intentionally false: dialogue and tool bodies are
represented by digests, while provider-private state, hidden reasoning, and
private prompts are not public data.

The public artifact repository is an append-only Git/PR evidence store, not a
JFrog Artifactory registry:

- MCPMark native receipts retain `summary.json` and each task's
  `meta.json`, final `messages.json`, and ordered `execution.log`.
- Tau2 native authority remains `results.json`; the accompanying
  `crucible_tau2_trajectory_snapshot.v3` file records the diagnostic assay,
  source digest, and `promotion_authority: none`.
- Portable behavior views use `geode.trajectory@1`. Each release contains
  only allowlisted trajectory JSON files and one
  `geode.trajectory-release@1` manifest.
- SQLite/WAL, runtime JSONL, mutable checkpoints, usage ledgers, provider
  diagnostics, hidden reasoning, credentials, and private prompts remain
  excluded.

The Telecom native receipt contains synthetic benchmark identity fields.
Phone and email values are redacted in the public copy and local absolute
paths are masked. The trajectory keeps the restricted raw-result digest
`eda3cdbdb9cd0c2f993db3f9fe2e813cdbc06fe9cf112e23ba60c7ea9d98a45b`;
the public redacted copy has SHA-256
`506f906cfa1d6e8e4320ba284be1aa0f7ec26ea2fc47b43e7b36f69e3643a9d4`.
That distinction prevents a privacy transform from being mistaken for the
native source authority.

## External-loop compatibility

- SIL keeps Inspect `.eval`, mutation and attribution ledgers, and executable
  verifier outputs authoritative. GEODE may attach an
  `inspect_ai.eval@native` digest reference, but a portable trajectory never
  replaces or silently promotes the SIL record.
- Crucible keeps frozen experiment contracts, Tau2 native receipts,
  `crucible.evidence.v3`, campaign state, and promotion decisions
  authoritative. These two runs are explicitly diagnostic and unfrozen, so
  their snapshots correctly keep `promotion_authority: none` and the
  trajectories expose only `native_receipt`, not `crucible_evidence`.
- The stable trajectory is therefore a correlation and replay sidecar for an
  external loop. Outcome authority remains with the loop's native verifier.

This boundary follows the current frontier split: Codex exposes a small public
lifecycle-hook surface while retaining typed internal events; Hermes uses four
request/execution middleware seams with stable observer correlation; OpenClaw
separates canonical SQLite transcript/runtime-event tables from JSONL
serialization boundaries. The grounded source revisions were Codex
`f0c30e528a54bdf0fa9a4d52ff74b34383434811`, Hermes Agent
`98105f31f46d3de58a8f69a2a439cee3f7a5e389`, and OpenClaw
`49b4841081c641e001d5744eccee842a2e4a0b41`.
