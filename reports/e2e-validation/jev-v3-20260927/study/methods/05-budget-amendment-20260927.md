# Jev v3 사전 등록 보완 · 예산 복구 조건

2026-09-27. 적용 범위는 사용자 승인에 따른 U 시리즈의 새 시간 예산 실행과 남은 U·X 비용 한도 확대다. 원본 05 v2.2 및 이미 동결·실행한 결과는 보존한다. 이 보완은 새 실행의 조건이며 기존 시행의 제한·유효성·분모를 소급 변경하지 않는다.

## 승인과 목적

사용자는 “버짓 재설정해서 중단된 사안들 측정 가능하게 만들어. 이후 후속 태스크까지 진행하고. U 시리즈를 말하는거야.”와 “X 시리즈도 비용 버짓 늘리면서 최종까지 넓혀.”라고 지시했다. 승인 영수증은 `codex-pre-freeze-20260927/remaining-u-preparation-20260927/budget-recovery-20260927/user-authorization.json`이다.

목적은 기존180초에 잘린 E2E의 전체 비교 단위를 새 시간 정책으로 측정하고, 비용 예약 때문에 시작하지 못한 X2를 완료하는 것이다. 측정 가능성이나 성공을 보장하지 않으며, 새 조건에서 실패해도 결과를 보존한다.

## 시간 예산의 근거와 적용값

코드는 최초 실행 이후 검증에 따른 재진입을 최대2회 허용한다. 각 physical turn은 round counter를 다시 시작하며 최대6rounds, 전체 경과 시계는 공유한다. 기존180초는 이미 최초·재진입 전체가 공유하던 trial ceiling이었다.

새 배분 규칙은 **종전180초를 명목 시간 단위로 삼아, 최대3 physical turns에 대응하는 전체540초를 배정**한다. `540 = 180 × (1 + 2)`에서3은 소스의 허용 깊이에서 왔다. 기준180초의 경험적 적정성은 입증되지 않았으므로540을 실측 최적값·사용자 SLO·최소 충분 시간으로 부르지 않는다. 실제 시계는 여전히 공유하므로 각 turn에180초를 따로 보장하는 것도 아니다.

| 경계 | 새 값 | 산정·유지 근거 |
|---|---:|---|
| root 전체 | 540초 | 위 구조적 운영 배분. loop 설정과 실제 wait_for에 같은 값 전달 |
| Harbor agent | 570초 | 540 + 기존 바깥 여유(210−180)=30 |
| host watchdog | 1,290초 | 기존930 + root 증분(540−180)=360 |
| setup / verifier / cleanup | 600 / 30 / 120초 | 기존 운영 경계 유지 |
| round / 검증 재진입 | 6 / 최대2회 | 기존 구조 유지 |
| 최종 판정 / helper / replan | 기존120 / 120 / 60초 경계 | 이번 변경으로 확대하지 않음 |

바깥 여유30초와 watchdog 잔여 여유의 충분성이 새로 실측됐다는 주장은 하지 않는다. Codex HTTP read300초는 읽기 정체 제한이며 스트리밍 호출 전체의 상한이 아니므로 시간 합산 근거로 사용하지 않았다.

전체 예산은 실행 정책에도 영향을 준다. 검증·수정용 reserve `min(300, budget/3)`는60→180초가 되고, 예산 안내·도구 차단 시점이 달라질 수 있다. 이는 단순히 외부 대기만 늘린 실험이 아니라 **새 시간 정책 조건**이다. 모델과 요청 effort는 Astra xhigh/Jev1.13.0으로 유지한다.

## 비용 예산 산식

새 작업 전 native 원장 검증상 관측 토큰에 따른 누적 추정비용은 **0.189710640달러**, 열린 예약과 미확정 토큰 예약은0이다. 이는 공급자 실제 청구액이 아니다. 기존1664 Jev 호출·정산·거부 기록은 그대로 둔다.

- X2는 기존 규칙대로480 Jev 셀과 교체 여지를 예약해960회, 회당25,000입력토큰과 동결 단가0.042달러/100만토큰을 적용한다. 예약액은 **1.008달러**다.
- 필요한 E admission4단위 및 U6b6·U8c36·조건부U8n36·U7 ABC36씩2회에 대한 기존 native 예약을 합하면 **873회**다.
- 미래 예약 합계 `(960 + 873) × 25,000 × 0.042 / 1,000,000 = 1.924650000달러`.
- 기존 소진을 포함한 계획 envelope는 `0.189710640 + 1.924650000 = 2.114360640달러`.
- 90% 시작 가드를 유지해 `envelope / 0.9 = 2.3492896`을 센트 단위로 올림한 **프로그램 cap2.35달러**, 시작2.115달러, 중단2.2325달러(95%)를 적용한다.

25,000토큰은 예약 가정이며 입력 hard maximum이 아니다. 실제 과다 소비·미정산·중단 가드는 유지하므로 이 계산이 완주를 보장하지 않는다. 실제 호출·토큰 수는 더 긴 실행 기회에 따라 늘어날 수 있다. Astra 구독의 원장·90% 투영/95% 중간 가드도 유지하며 그 비용을 Jev 달러 원장에 섞지 않는다.

원장 한도 변경은 승인 참조를 포함한 append-only amendment로 수행한다. 기본1달러·기존 header·과거 chain은 보존하며, 중단 상태나 unknown을 지우지 않는다. X2의 호출 전 거절 기록도 보존한다.
