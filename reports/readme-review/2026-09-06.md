## Retained legacy reproduction example

The following command appeared in the reviewed README for an
`eval-sys/mcpmark@cd45b7f` checkout with the historical GEODE package installed
editable in its virtual environment. It is retained verbatim as a reference,
**not a command for today's GEODE installation**. Reproduction requires the
selected run's exact GEODE revision, harness, environment, and run contract.

```bash
set -a; source .mcp_env; set +a
OPENAI_API_KEY=dummy \
.venv/bin/python -m plugins.benchmark_harness.run_mcpmark \
  --mcp <service> --task-suite <easy|standard> \
  --models geode-gpt-5.5 --agent geode --reasoning-effort xhigh \
  --k 1 --timeout 1200 \
  --exp-name <run-id> --output-dir ./results-geode-agentworld
```

In that legacy setup, `OPENAI_API_KEY=dummy` satisfied the upstream environment
check; model calls used GEODE's subscription provider. The companion tau2 path
was `plugins/benchmark_harness/tau2_geode_agent.py`. Neither historical path is
restored by this documentation change, and no live model calls were made.
